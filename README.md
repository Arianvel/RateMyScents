# RateMyScents

Explore your fragrance collection, get recommendations based on your preferences, and create a My 9 Scents grid to share.

Available in English and Spanish, with light and dark themes.

## Run locally

Open `index.html` with VS Code's Live Server extension or another static HTTP server. No build step or npm installation is required.

## GitHub Pages

In Settings > Pages, choose **Deploy from a branch**, select your website branch and **/ (root)**.

The site requires `index.html`, `styles.css`, `scents.json` and the `js/` folder. Fonts load from Google Fonts, with system fonts as a fallback.

Collections and quiz answers stay in browser memory and reset on reload. See **How it works** on the website for the scoring method.
